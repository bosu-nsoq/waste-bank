# ♻️ Waste bank - ระบบธนาคารขยะ

> **ระบบธนาคารขยะดิจิทัล** สำหรับโรงเรียนและสถาบันการศึกษา สะสมคะแนน แลกของรางวัล และร่วมอนุรักษ์สิ่งแวดล้อม  
> พัฒนาด้วย **Google Apps Script**, **Google Sheets** และพร้อมเปิดใช้งานผ่าน **GitHub Pages** (Progressive Web App)

## 🌟 คุณสมบัติเด่นของระบบ

### 1. 👥 ระบบ 2 โหมดการใช้งาน (Guest & Admin)
- **โหมดทั่วไป (Guest / นักเรียน)**:
  - 🔍 **ตรวจสอบคะแนนสะสม (Passbook)**: ค้นหาด้วยรหัสนักเรียน 4 หลัก แสดงยอดคะแนนคงเหลือ และประวัติการฝาก/แลกคะแนนย้อนหลัง
  - 📋 **อัตราคะแนนรับฝากขยะ (Price List)**: ตรวจสอบประเภทขยะรีไซเคิลและอัตราคะแนนที่จะได้รับต่อชิ้น/กิโลกรัม
  - 📊 **สถิติ & กระดานเกียรติยศ (Leaderboard)**: ตรวจสอบอันดับนักเรียนที่มีคะแนนสะสมสูงสุด 10 อันดับแรก และสถิติขยะยอดนิยม
- **โหมดผู้ดูแลระบบ (Admin / เจ้าหน้าที่)**:
  - 🔐 **เข้าสู่ระบบด้วย PIN 4 หลัก**: รองรับ **รหัส PIN = `8055`** (Master PIN) หรือกำหนดรายบุคคลในตารางชีต `Settings`
  - 📥 **ทำรายการฝากขยะ (Deposit)**: ค้นหานักเรียนอัตโนมัติ, เลือกประเภทวัสดุ, ระบบตะกร้าคำนวณคะแนนแบบเรียลไทม์, บันทึกการฝาก
  - 🎁 **ทำรายการแลกคะแนน (Withdraw)**: ค้นหานักเรียน, เช็คยอดคงเหลือ, ตรวจสอบไม่ให้แลกเกินคะแนนที่มี, บันทึกตัดคะแนน
  - 🖨️ **รายงานและประวัติ (Report & Print)**: กรองตามช่วงวันที่ (ตามมาตรฐาน พ.ศ.), สรุปยอดฝาก-แลก-คะแนนหมุนเวียนสุทธิ, สั่งพิมพ์รายงานขนาด A4 ทันที

### 2. ⚡ ทำงานลื่นไหล ทันสมัย (Smooth & Fluent UX)
- แจ้งเตือนสวยงามด้วย **SweetAlert2** (ไม่มีหน้าต่าง alert โบราณขัดจังหวะ)
- เสียงตอบรับสัมผัส (Audio Chime) เมื่อบันทึกรายการสำเร็จ
- แคชข้อมูลนักเรียนและราคาในเครื่องเพื่อค้นหาได้ทันทีโดยไม่ต้องรอโหลดซ้ำ
- รองรับการแตะตัวเลขสัมผัส (Touch Numpad) ใช้งานง่ายบนมือถือ

### 3. 📱 รองรับการใช้งานทั้งคอมพิวเตอร์และมือถือ (Mobile Portrait Responsive)
- Header แถวเดียว ไม่ตัดบรรทัดบนมือถือแนวตั้ง (`white-space: nowrap`)
- คอมพิวเตอร์แสดงชื่อผู้ใช้งานเต็มครบถ้วน ไม่ตัดย่อ
- ฟอนต์สอดคล้องตามมาตรฐาน:
  - ฟอนต์ **'Mali'** สำหรับหน้าจอระบบและการใช้งานที่เป็นมิตรกับนักเรียน
  - ฟอนต์ **'Sarabun'** (สารบรรณ) สำหรับเอกสารรายงานและสั่งพิมพ์ทางการ
- ปฏิทินเลือกวันที่: คลิกเปิดเลือกวันได้ทันทีโดยไม่มีไอคอนปฏิทินรกในช่อง ตามมาตรฐานรูปแบบ **วัน/เดือน/ปี พ.ศ. (`dd/mm/yyyy`)**

### 4. 📲 ติดตั้งเป็นแอปบนมือถือได้ฟรี (PWA for iOS & Android)
- รองรับการติดตั้งลงหน้าจอโฮม (Add to Home Screen) เป็นแอปพลิเคชันแบบเต็มจอ (Standalone)
- ไม่ต้องเสียค่าธรรมเนียมรายปีของ App Store / Google Play Store

## 📁 โครงสร้างไฟล์ในโปรเจกต์

| ชื่อไฟล์ | คำอธิบาย |
|---|---|
| **`index.html`** | หน้าเว็บหลักสำหรับเปิดใช้งานบน **GitHub Pages** (มีระบบเชื่อมต่อ Apps Script อัตโนมัติ) |
| **`Page.html`** | หน้าเว็บสำหรับใช้งานโดยตรงบน **Google Apps Script Web App** |
| **`Code.gs`** | โค้ดหลังบ้าน Apps Script สำหรับจัดการฐานข้อมูล Google Sheets และ API (`doGet` / `doPost`) |
| **`manifest.json`** | การตั้งค่า Progressive Web App (ชื่อ, ไอคอน, สีธีม, หน้าจอแนวตั้ง) |
| **`sw.js`** | Service Worker สำหรับจัดการแคชและประสิทธิภาพของ PWA |
| **`appsscript.json`** | ไฟล์ Manifest ของ Google Apps Script |
| **`.clasp.json`** | การตั้งค่าสำหรับ Google Clasp CLI |

## 🚀 วิธีตั้งค่าและการนำขึ้นใช้งาน

### ขั้นตอนที่ 1: ตั้งค่าบน Google Apps Script
1. เปิดโปรเจกต์ Google Apps Script (Script ID: `1p7TBhgvIctwB854mT3PJLdmR_Q54a20mGxYa3o7jqVkP5stFYxAZHqD1`)
2. วางโค้ดจาก `Code.gs` ลงในไฟล์ `Code.gs`
3. สร้างไฟล์ HTML ชื่อ `Page` แล้วนำโค้ดจาก `Page.html` ไปวาง
4. กด **การทำให้ใช้งานได้ (Deploy)** -> **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ชนิด: **เว็บแอป (Web app)**
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้ GitHub Pages เรียกข้อมูลได้)*
5. กด **ทำให้ใช้งานได้ (Deploy)** แล้วคัดลอก **URL เว็บแอป (Web App URL)**

### ขั้นตอนที่ 2: เปิดใช้งานบน GitHub Pages
1. ไปที่ Repository [https://github.com/bosu-nsoq/waste-bank](https://github.com/bosu-nsoq/waste-bank)
2. ไปที่เมนู **Settings** -> **Pages**
3. ในส่วน **Build and deployment** -> เลือก Branch: `main` / Folder: `/ (root)` แล้วกด **Save**
4. รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ เช่น `https://bosu-nsoq.github.io/waste-bank/` พร้อมเปิดใช้งานได้ทันทีบนทุกอุปกรณ์!

*(หากต้องการเปลี่ยน Web App URL ในอนาคต สามารถกดที่ไอคอน **⚙️ ตั้งค่า API** ที่ด้านล่างของหน้าเว็บได้ทันที)*
